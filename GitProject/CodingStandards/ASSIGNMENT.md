# Assignment - Coding Standards

*Lesson: [Coding Standards](README.md)*

**Due:** End of class (in-class work, nothing to submit)

---

## Why Today

Every student built the same Git, and every project was different: different method names, different signatures, different behaviors when something went wrong, and different ways of solving each problem. You felt it in Parts 4 and 5, every time you had to learn someone else's code before you could add to it.

Coding standards fix that. Today you write them.

---

## Round 1: Partners (about 10 minutes)

With a partner, list the rules you wish every Git project had followed. Aim for at least one rule in each area:

| Area | Questions to answer |
|---|---|
| **Syntax and formatting** | Indentation, braces, line length, blank lines. |
| **Naming** | How are classes, methods, variables, and constants named? Full words or short? |
| **Method signatures** | What does each operation take in and give back? Paths as `String` or `File`? |
| **Behavior and errors** | What happens with a missing file, a folder, a repeated call? Throw, print, or ignore? |
| **Data structures** | Lists, maps, arrays, or plain strings for the index and trees? |
| **Java version and libraries** | Which Java version? What is allowed beyond the standard library? |
| **Files and layout** | One class or many? Where do tests live? What goes in `README.md`? |
| **Comments and commits** | What must every method's comment say? What does a good commit summary look like? |

---

## Round 2: Groups of Four (about 10 minutes)

Join another pair.

1. Read both lists out loud.
2. Combine them into **one list of your group's ten most important rules**, most important first.
3. For each rule, write one sentence on the problem it prevents.
4. Pick one person to speak for the group.

---

## Round 3: Share Out (5 minutes per group)

Your speaker presents the group's top rules to the class. As the class listens, note every rule that more than one group chose: those are the class's standards.

---

## Success Criteria

- [ ] **Your pair covered every area** in the Round 1 table.
- [ ] **Your group agreed on ten rules,** ranked, each with the problem it prevents.
- [ ] **Your group shared out** in five minutes or less.
