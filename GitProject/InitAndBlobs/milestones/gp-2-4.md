# GP-2.4 — Update the Index File

*Part of the [Initialization and Blobs](../ASSIGNMENT.md) assignment*

---

## Recall

The index is a plain text file at `git/index` that lists every staged file. Each line contains a SHA-1 hash, a single space, and the file's relative path. Staging is manual — files must be explicitly added.

See [Docs/index-file.md](../../Docs/index-file.md) for details.

---

## Instructions

> **Branch reminder:** Branch?

Create a method that adds a file entry to `git/index` in this format:

```
553ae7da92f5505a92bbb8c9d47be76ab9f65bc2 myProgram/filename.txt
077bd0b932707f2e7c00ee0147535b386ea6751b myProgram/anotherFile.txt
```

Each line: SHA-1 hash, one space, relative path. Nothing else.

> **Warning:** No trailing space after the path. No blank line at the end of the file.
