# GP-2.1 — Initialize a Repository

*Part of the [Initialization and Blobs](../ASSIGNMENT.md) assignment*

---

## Recall

When a Git repository is initialized, a hidden `.git` folder is created to store the entire history of the project. In this project, your program creates the equivalent structure in a `git/` directory — not `.git/`, since that already exists and is managed by real Git.

> **Note:** The `git/` your program creates and the `.git/` folder from GitHub are completely separate. Your `.gitignore` entry for `/git` keeps your simulated repository from being committed to GitHub.

---

## Instructions

> **Branch reminder:** Create a new feature branch before writing any code. Never program directly in `main`.

Write a program that initializes a Git repository by performing the following steps **in order**:

1. Create a `git/` directory if it does not already exist
2. Create an `objects/` directory inside `git/` if it does not already exist
3. Create a file named `index` inside `git/` if it does not already exist (no extension)
4. Create a file named `HEAD` inside `git/` if it does not already exist (no extension)
5. If **all four** already exist, print:
    ```
    Git Repository Already Exists
    ```
    Otherwise print:
    ```
    Git Repository Created
    ```

Update your `README.md` with the method name(s) that initialize the repository and any challenges you encountered.
