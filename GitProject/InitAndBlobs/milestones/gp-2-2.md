## Recall

A hash function takes any input and produces a fixed-length output. SHA-1 always produces a 40-character hexadecimal string. The same input always produces the same output — and no two different inputs should produce the same output (a "collision").

Git uses SHA-1 to give every file a unique identifier based on its content. SHA-1 is no longer used for cryptographic security, but for file identification it is exactly what we need.
