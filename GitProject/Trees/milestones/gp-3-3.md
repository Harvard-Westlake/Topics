## The Working List

A **working list** starts as a copy of the index with `blob` prefixed on each line. It is then compressed directory by directory until only the root tree entry remains. The working list is a runtime data structure — it does not need to be saved to disk permanently.

**Why the working list exists:** Trees must be built bottom-up. You cannot hash a parent directory until all its children are resolved. The working list lets you track which directories are fully resolved and which still have unprocessed children.

---

## The Algorithm

**Step 1 — Build and sort the working list**

Copy the index, prefix `blob` on each line, then sort by path name so subdirectories are grouped:

```
blob 0a4d55a8d778e5022fab701977c5d840bbc486d0 myProgram/docs/Hello.txt
blob 483b5e082cf5502b303ba3dd4f3469a49fd3421f myProgram/docs/World.txt
blob 4377a91cdfd44db9a9bbf056849c7da0fc6cc7be myProgram/README.md
blob 4a5d9f8b10c2de34567890abcdef1234567890ab myProgram/sample.txt
```

**Step 2 — Find the leaf-most directory**

The first two entries share `myProgram/docs`. Create a tree file for it:

```
blob 0a4d55a8d778e5022fab701977c5d840bbc486d0 Hello.txt
blob 483b5e082cf5502b303ba3dd4f3469a49fd3421f World.txt
```

Hash it — say it produces `d7d25fb30eba405a2c705f5a48f20dd423beb30f`.

**Step 3 — Collapse the working list**

Replace both entries with a single `tree` entry:

```
tree d7d25fb30eba405a2c705f5a48f20dd423beb30f myProgram/docs
blob 4377a91cdfd44db9a9bbf056849c7da0fc6cc7be myProgram/README.md
blob 4a5d9f8b10c2de34567890abcdef1234567890ab myProgram/sample.txt
```

**Step 4 — Repeat**

The remaining entries all belong to `myProgram`. Create its tree file:

```
tree d7d25fb30eba405a2c705f5a48f20dd423beb30f docs
blob 4377a91cdfd44db9a9bbf056849c7da0fc6cc7be README.md
blob 4a5d9f8b10c2de34567890abcdef1234567890ab sample.txt
```

Collapse again. Continue until only one entry remains — the root tree.

## Instructions

Implement the working list algorithm described above. Your method should:

1. Build a working list from the index (prefix `blob`, sort by path)
2. Repeatedly find the leaf-most directory and create its tree file in `git/objects/`
3. Collapse that directory's entries into a single `tree <hash> <dirname>` entry
4. Repeat until only a root tree entry remains
5. Return or store the root tree's SHA-1 hash — `commit()` in Part 4 will need it
