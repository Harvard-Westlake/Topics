# GP-3.2 — Create a Basic Tree

*Part of the [Trees](../ASSIGNMENT.md) assignment*

---

## Recall

A tree file represents a directory. Each line in a tree file identifies a blob (file) or another tree (subdirectory) with its hash and name. Trees must be built from the inside out — innermost directories first — because a parent tree needs each child's hash before it can be written.

See [Docs/trees.md](../../Docs/trees.md) for the file format and a worked example.

---

## Instructions

> **Branch reminder:** No seriously, what ARE those things sticking out of trees called? (Create one.)

Implement a method that, given a directory path as a String:

1. Generates a tree file containing references to all files and subdirectories in that directory
2. Returns the SHA-1 hash of the generated tree

**For each file in the directory:**
- Generate a blob in `git/objects/`
- Add a line to the tree file:
    ```
    blob <SHA1> <filename>
    ```

**For each subdirectory:**
- Recursively call your method on the subdirectory first
- Use the returned hash to add a line to the parent tree file:
    ```
    tree <SHA1> <directoryname>
    ```

> **Note:** This method creates trees from any directory path, regardless of what is in the index. In GP-3.3, you will build the version that creates trees only from staged files — the one `commit()` will actually use.
