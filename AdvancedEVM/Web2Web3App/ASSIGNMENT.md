## Project

You are to create a web3 contract which serves a purpose.

You are to add a page to your website which can run your web3 code.

You are encouraged to reference the **Web3VoteExample** shown in class — it has working code to the blockchain and can be interacted with. You are also encouraged to get as much Sepolia ETH as you can **each day** ([faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia)). You WILL need it.
