# Review — The Four-Command Round Trip

*Originally covered in [Terminal Basics](../README.md)*

---

| Command | What it does |
|---|---|
| `pwd` | Print the folder your terminal is standing in |
| `mkdir name` | Create a folder called `name` here |
| `cd name` | Step into the folder called `name` |
| `cd ..` | Step out to the parent folder |

---

## Tasks

1. In your terminal, run `pwd` and record the path — this is your starting point.
2. Create a folder with `mkdir HTCS_Practice` (if it already exists from before, just continue).
3. Step inside it with `cd HTCS_Practice`, then run `pwd` and record the path — it should have grown by exactly one folder.
4. Step back out with `cd ..`, then run `pwd` a third time — it must match your starting point exactly.
5. Write one sentence: after step 3, what would `mkdir notes` create, and where would it live?
