# Review — Terminal Basics, Day 1

*Originally covered in [Terminal Basics](../README.md)*

---

| Command | What it does |
|---|---|
| `pwd` | Print your current location as an absolute path |
| `cd path` | Move to a folder — relative or absolute |
| `ls` | List folder contents |
| `ls -lsa` | List with size, permissions, hidden files, and dates |
| `mkdir name` | Create a folder |
| `touch name` | Create an empty file |

Path shortcuts: `.` = here · `..` = one level up · `~` = home · `/` = root

---

## Tasks

1. Open your terminal. Print your current location.
2. Navigate to your home directory.
3. Create a folder called `practice`. Navigate into it.
4. Create two files: `one.txt` and `two.txt`.
5. List the contents of `practice` in long format. Confirm both files appear.
6. Navigate back to your home directory in a single command.
