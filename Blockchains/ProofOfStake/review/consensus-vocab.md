# Review — Consensus Vocabulary

*Originally covered in [Proof of Stake](../README.md)*

---

| Term | Meaning |
|---|---|
| PoW (Proof of Work) | Miners burn computation to win the right to save a block |
| Hash difficulty | Required leading zeros that make block hashes expensive to find |
| Block reward | Newly minted coins paid to whoever saves the block |
| PoS (Proof of Stake) | Validators secure the network by staking their own tokens |
| Validator | Stakes tokens to validate transactions and create blocks |
| Staking | Locking tokens as collateral to participate |
| Consensus | Agreement among nodes on the ledger's contents |
| Slashing | Losing stake for cheating or bad validation |
| Delegation | Appointing others to validate on your behalf |
| Epoch | Fixed period for validation and reward distribution |
| Finality | Point past which transactions cannot be reversed |
| Bonding period | Time staked tokens stay locked |
| Nonce | Effort-proving value from PoW; less relevant in PoS |
| Governance | Token-holder voting on network changes |
| Capital efficiency | Securing the network with committed capital, not spent energy |

---

## Tasks

1. Sort the table's terms into three piles: PoW-only, PoS-only, and shared by both. Defend one placement out loud.
2. Write one sentence describing a single block's confirmation under PoW, then rewrite the same sentence under PoS, changing only the words that must change.
3. A validator signs two conflicting histories during the same epoch. Name what happens to their stake, and which term describes it.
4. Using ledger, transaction, hash link, and consensus in one paragraph, explain why both PoW and PoS chains resist rewriting old blocks.
5. Rank the following by energy consumed to secure one block — Bitcoin, post-merge Ethereum, your classroom simulation — and justify the ranking in one sentence each.
