# Assignment — Code Review and MVP Presentation

**Due:** Presentation day (next class)

**Points:** 500

---

## Instructions

1. **Prepare the team demo (6 minutes)** — MVP statement in one sentence, proof you are on `main` (branch + commit hash), the happy path run end-to-end, and a closing on scope + known issues against the tech spec
2. **Prepare your individual deep dive (2 minutes)** — your issue + PR, a 10–25 line snippet from `main` with file path and function/class/component name, the technical challenge and solution, and your verification evidence + reviewer
3. **Prepare answers to the 3 required questions** — execution path trace, which tech spec section your code completed, and what your code integrates with
4. **Assemble the submission** — one team-tracking issue plus your individual text submission (see below)

---

## Grading Rubric (500 points total)

> **Note:**
> Part 1 is a **team score** (same for all teammates). Part 2 is an **individual score** (earned per student).

| Category | Full credit looks like | Points |
|---|---|---|
| **Part 1: MVP Demo (Team, 6 minutes)** | MVP stated clearly and matches what is demoed; demo runs on `main`; **happy path + one failure case** shown with no crashes; scope/known issues stated; smooth handoff and pacing. | **150** |
| **Part 2: Individual Deep Dive (2 minutes each)** | Shows merged work in `main` (issue/PR + snippet); explains how it works with real names/paths/data; answers all 3 required questions concretely; shows verification; includes code review evidence and what changed because of review. | **350** |

### Common point deductions (applies to either part)

- Talking about other people, work you did not do, or things you did not deliver
  - Do: talk about code **you** wrote and problems **you** solved
- Demo not run from `main` / cannot prove `main` state: **major deduction**
- Vague explanations ("it just works" / "AI wrote it" / no file or function references): **deduction**
- No verification evidence (tests or repeatable reproduction): **deduction**
- No code review evidence: **deduction**
- No clear visual of tech spec progress (both individual and as a team): **deduction**
