## Instructions

1. **Refactor** — organize your code into classes and methods, standardize formatting, update your tech spec where the implementation drifted from it, and make sure your code is not all in one file
2. **Understand** — write a plain-English explanation of each function; note any parts you do not fully understand (including AI-generated code) so they can be troubleshot together
3. **Document** — write your project's `README.md` (setup, key parts of the code, special tools, how to run it) and update `MVP.md` (everything completed so far, next steps, where the project is headed)
4. **Commit and push** — by the end of today, your repository must contain the cleaned-up code, the README.md, and the updated MVP.md

Next class, someone else will use your documentation to run your project. The goal is that it makes sense to a person seeing it for the first time.
