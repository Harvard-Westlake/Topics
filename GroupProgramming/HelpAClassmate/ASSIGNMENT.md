# Assignment — Help a Classmate

*Lesson: [Help a Classmate](README.md)*

**Duration:** 2 class periods  
**Due:** End of each class period (one run per class, a different classmate's project each time)

**Points:** 100 per run

---

## Instructions

For each run:

1. **Fork** your assigned classmate's repository
2. **Clone** your fork to your machine
3. **Follow the instructions in their README.md** to get their project up and running
4. **Solve one of the features in their MVP.md** — work in a feature-named branch with meaningful commits
5. **Update their MVP.md** to reflect what you completed
6. **Submit a pull request** back to their repository with a clear description of the purpose and changes

---

## Point split (100 points)

- **50** for getting it up and running
- **25** for adding a feature that is working
- **10** for updating the MVP.md
- **15** for a pull request

## Success Criteria

Confirm each of the following before submitting (each run):

- [ ] **Forked and cloned** — you worked on your own fork, in a feature-named branch, never directly on their `main`
- [ ] **Running from their README** — you got their project running by following their instructions
- [ ] **Feature works** — you implemented an MVP.md feature (the top priority, or a more sensible choice) and it functions
- [ ] **MVP.md updated** — their MVP.md reflects what you completed
- [ ] **Pull request submitted** — a well-documented PR back to their repository, with at least 3 meaningful commits behind it
