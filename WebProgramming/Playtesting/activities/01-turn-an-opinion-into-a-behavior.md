# Activity - Turn an Opinion Into a Behavior

*Concept: Take feedback that only says how someone felt and rewrite it as what they did and what the screen did.*

![Three opinions, each rewritten as a behavior. It was fun becomes: I played six rounds and only stopped because class ended. The buttons were confusing becomes: I tapped the gray box three times before I saw it was not a button. Good design becomes: the score grew bigger each time I got one right, so I kept watching it. A caption says nobody can fix confusing, and anybody can fix a gray box that looks like a button.](../assets/opinion-vs-behavior.svg)

## Task

1. Open any website or game you used this week. Use it for one minute.
2. Write the first three words that come to mind about it, such as "fun", "slow", or "confusing".
3. For each word, write the moment that caused it: what you did, and what the screen did.
4. Cross out the three words. Read only the moments to a neighbor.
5. Ask the neighbor which moment the builder should fix first. They can answer without ever seeing the site.
