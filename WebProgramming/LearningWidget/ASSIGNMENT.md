# Assignment — The Learning Widget Project

**Duration:** 2 class periods  
**Due:** Phases 1 and 2 before next class; Phase 3 by the end of the project window  
**Points:** 100

---

## Overview

Research, design, plan out, and build an educational widget for a topic which is not easily understood or visualized — following the three phases in the [lesson](README.md), in order. It can be ANY topic, but it has to be approved by your teacher. The look must match the styles at [learnhw.web.app/admin](https://learnhw.web.app/admin) exactly.

---

## Classwork — complete before next class

1. **Research and get approval for a topic.** Check what already exists online (ask AI to search too), then propose to your teacher.
2. **Plan out** the way your widget will make the topic more easily understood, and how each of the parts interact. Save the plan in a `PLAN.md` file in your fork of the project repository.
3. **Commit and push this work** — the plan must be committed *before* AI rewrites or formats it.

---

## Build — complete by the end of the project window

1. Create a branch in your fork and code the entire widget there, using Cursor
2. Publish to GitHub and deploy to your live website via Firebase — add a button on your main website that links to the widget
3. Open a pull request containing your final submission

---

## Success Criteria

Confirm each of the following before submitting:

- [ ] **Topic approved** — your teacher explicitly approved the topic before you planned it
- [ ] **PLAN.md committed first** — the plan's first committed version predates all widget code and all AI formatting
- [ ] **Built on a branch in your fork** — no commits straight to the default branch
- [ ] **Style parity** — the widget uses the same styles as [learnhw.web.app/admin](https://learnhw.web.app/admin)
- [ ] **Live and linked** — the widget is deployed via Firebase and reachable from a button on your main website
- [ ] **Pull request open** — the PR contains the final widget and a clear description of what it teaches
- [ ] **Console clean** — zero errors on load and during use
