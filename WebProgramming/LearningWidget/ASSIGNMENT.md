# Assignment - The Learning Widget Project

*Lesson: [The Learning Widget Project](README.md)*

**Duration:** 2 class periods  
**Due:** Before the start of the next lesson's class

---

## What to Build

An educational widget for one hard-to-understand topic, approved by your teacher, live on your website.

| Result | What it means |
|---|---|
| **An approved topic** | Your teacher said yes to the topic before you planned it. |
| **A plan that came first** | `PLAN.md` in your fork, in your own words, committed before any widget code and before any AI rewrite. |
| **Built on a branch** | Every widget commit is on a branch in your fork, not the default branch. |
| **It remembers** | A learner's progress survives a reload (local storage or Firestore). |
| **House style** | The look matches [learnhw.web.app/admin](https://learnhw.web.app/admin). |
| **Live and linked** | Deployed on your Firebase site and reachable from a button on your main page. |
| **Clean console** | Zero errors on load and during use. |
| **A pull request** | Open, with a description of what the widget teaches. |

## Success Criteria

- [ ] **Topic approved:** your teacher approved the topic before you planned it.
- [ ] **Plan committed first:** the first version of `PLAN.md` comes before all widget code and all AI formatting in your history.
- [ ] **Built on a branch:** no widget commits on the default branch.
- [ ] **Remembers the learner:** progress survives a reload.
- [ ] **Style match:** the widget uses the learnhw.web.app/admin styles.
- [ ] **Live and linked:** the widget is deployed and reachable from your main page.
- [ ] **Console clean:** zero errors on load and during use.
- [ ] **Pull request open:** it contains the widget and says what it teaches.
