## What to Build

Two pieces of interaction on your website, each in its own JavaScript file:

| Result | What it means |
|---|---|
| **A basic interaction** | One file reacts to at least one user event (a click, a key, the mouse) by visibly changing the page. |
| **A bigger feature** | A second file builds something with real logic: a small game, interactive art, or something similar. Not just another button. It uses at least one class. |
| **Linked and running** | Both files are linked from your HTML and run on the page. |
| **No errors** | The page loads with no errors in the browser console, or you can explain every one that remains. |
| **Live** | Both interactions work on your live `*.web.app` site, not just on your laptop. |

**Verify:**

1. Open your live site with the console open (`Cmd+Option+J` on Mac, `Ctrl+Shift+J` on Windows).
2. Use both features. Each one visibly changes the page.
3. Read the console. It is empty, or every error is one you can explain.

---

## Success Criteria

- [ ] **Two JavaScript files:** both are linked from your HTML and run on the page.
- [ ] **Basic interaction works:** the first file visibly responds to a user event.
- [ ] **Bigger feature works:** the second file uses real logic and at least one class.
- [ ] **No unexplained errors:** the console is empty, or each remaining error is explained.
- [ ] **Deployed:** both work on your live `*.web.app` URL.
