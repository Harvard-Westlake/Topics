# Assignment - Widget Iteration from Feedback

**Lesson:** [Widget Iteration from Feedback](README.md)  
**Due:** Before the start of next class

---

## What to Build

Your Learning Widget with every piece of tester feedback handled, and no errors.

| Result | What it means |
|---|---|
| **feedback.md committed** | It entered your repository holding your testers' comments word for word. |
| **Every item handled** | Each comment is fixed in the widget, and the file shrank commit by commit until it was deleted. |
| **Silent on load** | The Console shows zero errors when the widget loads. |
| **Silent in use** | Zero errors appear while every interaction is tried. |
| **Pull request updated** | The new commits are pushed, the PR has a comment summarizing what changed, and the live site matches. |

**Verify:**

1. Open your repository's commit history. You can watch `feedback.md` arrive, shrink, and disappear.
2. Open the live widget in a private window with the Console showing, and use every part of it. Nothing turns red.

> **Note:** The only allowed exception is an error from the browser or an extension rather than your own code. Check with your teacher first.

---

## Success Criteria

- [ ] **feedback.md committed:** the file entered the repository with your testers' exact words.
- [ ] **Feedback implemented:** every item is fixed, and the file shrank until it was deleted.
- [ ] **Console silent on load:** zero errors when the widget loads.
- [ ] **Console silent in use:** zero errors while every interaction is tried.
- [ ] **Pull request updated:** new commits pushed, with a comment summarizing the changes.
