# Assignment — Widget Iteration from Feedback

**Due:** Next class

---

## Implement Feedback → Assure Quality

1. Add a `feedback.md` file to your repository with the **exact feedback** taken from your peers
   - Commit the `feedback.md`
   - As you continue to code, continually reduce the size of `feedback.md` until you no longer need it and it is deleted
2. Take into account **each item** of your feedback and implement it into your widget
3. Update your pull request with the updated items

**You must then:**

- Inspect the HTML of your widget in DevTools and verify:
  - **0 behavioral errors** happen on page load
  - **0 errors** appear as your widget is used — exercise every interaction with the console open
- Fix any errors!

> **Note:**
> The only allowed exception is an error that originates from the browser or an installed extension rather than your own code — confirm with your teacher if you believe an error qualifies.

---

## Success Criteria

Confirm each of the following before submitting:

- [ ] **feedback.md committed** — the file entered the repo containing your peers' feedback verbatim
- [ ] **Feedback implemented** — every item was addressed in the widget, and the file shrank commit by commit
- [ ] **Console silent on load** — DevTools shows zero errors when the widget loads
- [ ] **Console silent in use** — zero errors appear while every interaction is exercised
- [ ] **PR updated** — the pull request contains the new commits, pushed, with a comment summarizing the changes
