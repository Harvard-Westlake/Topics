# Website Inspiration
*<font color="#8b949e">Curated examples of innovative UX and interactive design worth studying</font>*

</div>

---

Visit these with a designer's eye, not a player's: notice how fast each one engages you, how it teaches its controls without instructions, and what its click and scroll heatmaps would look like. Used in [UX and Behavior Tracking](../UXAndBehaviorTracking/).

| Site | Why it is worth studying |
|---|---|
| [Koalas to the Max](https://www.koalastothemax.com/) | One mouse-move interaction, zero instructions — the mechanic teaches itself in a second and stays compelling to the end |
| [The Deep Sea](https://neal.fun/deep-sea/) | Scrolling itself becomes the experience — a running depth meter turns a page gesture into exploration |
| [Google Doodle: Celebrating Popcorn](https://doodles.google/doodle/celebrating-popcorn/) | A complete game in a page corner — instant load, instant comprehension, tight scope |
| [p5.js sketch](https://editor.p5js.org/JuanLopez713/sketches/wxBo3w502) | Creative coding — a small program producing outsized visual play, with the source right next to the canvas |
| [Vegetal](https://sophie006liu.github.io/vegetal/) | A student-built interactive site on GitHub Pages — proof that this level of polish is reachable from where you are |
| [Penguin Diner (Friv)](https://www.friv.com/z/walkthroughs/penguindiner.html) | Classic casual-game UX: escalating difficulty and constant feedback keep users "one more round"-ing |
| [Kubera (Webtoons)](https://www.webtoons.com/en/fantasy/kubera/season-3-ep-326-n20-12/viewer?title_no=83&episode_no=626) | Vertical-scroll storytelling — pacing, reveals, and flow controlled entirely by the scroll gesture |
| [Juxtopposed: redesigning UI (YouTube)](https://www.youtube.com/watch?v=cDY2p1CTkPo) | A designer redesigns familiar interfaces on camera — watch the reasoning behind each UX decision |
