# The Model Museum
*<font color="#8b949e">A cumulative comparison directory — every assignment adds one exhibit</font>*

</div>

---

At the end of every assignment, add one entry to a cumulative comparison directory:

```text
museum/
├── 01-tokenizer/
├── 02-bigram/
├── 03-fixed-attention/
├── 04-trainable-bigram/
├── 05-object-network/
├── 06-scalar-autograd/
├── 07-dense-network/
├── 08-single-head/
├── 09-transformer-block/
├── 10-trained-transformer/
└── 11-capstone/
```

## <font color="#388bfd">What Every Entry Contains</font>

- Configuration
- Parameter count
- Context length
- One trace
- One generated example
- One known failure
- Validation result
- Random seed
- Git commit identifier

This turns progress into something visible. You are not merely replacing old assignments; you are assembling a lineage of increasingly capable models. The Markov model is not forgotten after Week 2. The scalar engine is not discarded after the dense engine appears. Each model becomes a reference point.
