# Assignment — Combining Tech Specs

**Due:** End of class

---

In priority groups, combine your individual technical specifications into a single, comprehensive, color-coded document — core features first. This assignment is worth **15 pts**.

## Steps

1. Form groups by **highest** priority (if you are in 2 high-priority groups, pick the higher; groups over 3 people merge-sort their branches in pairs)
2. Review each member's spec and agree on structure — user flows, class dependencies, relationships — resolving conflicts for consistency
3. Combine the draw.io diagrams by dragging and dropping them together; use separate page tabs for unrelated systems
4. Color code by priority: **green = core, yellow = secondary, orange/red/purple = non-essential**
5. Create a branch named **`Merge_<FeatureName>`** for the group; cherry-pick or merge the significant commits, soft-locking the diagram file to avoid concurrent XML edits
6. **Stop when all core features are merged within groups** — then merge the core groups together before any secondary feature; every later session starts from the branch you already merged

---

## Success Criteria

Confirm each of the following before submitting:

- [ ] **Merge branch exists and is named `Merge_<FeatureName>`** — one per group
- [ ] **Combined diagram is one file** — teammates' diagrams merged, unrelated systems on separate page tabs
- [ ] **Priority colors applied** — every item is green, yellow, or orange/red/purple, and the order of work is visible at a glance
- [ ] **No XML casualties** — the `.drawio` file opens cleanly; concurrent edits were avoided by soft locking
- [ ] **Core merged before secondary** — no non-essential feature entered the combined spec before all core features were in
