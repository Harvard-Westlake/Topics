# Assignment — Group Design Review

*Lesson: [Group Design Review](README.md)*

**Due:** End of class

---

Design-review the 3 projects you have the highest financial influence toward, following the full review process from [Design Review](../DesignReview/README.md), with added emphasis on user-experience and application-design feature additions. This assignment is worth **20 pts**.

## Steps

1. Become a collaborator on all three repositories (fork if an owner is absent); add collaborators to your own project
2. For each of the three designs, in a **new branch**:
   - Review clarity, completeness, and implementation drift
   - Check for Honor Code and law violations
   - Add constructive ideas — including new **user experience** and **overall application design** ideas
3. Commit each review and open a pull request — **3 open pull requests, each in its own branch**

---

## Success Criteria

Confirm each of the following before submitting:

- [ ] **Three open pull requests** — one per reviewed project, all still open at submission time
- [ ] **Each PR in its own new branch** — no review work on any `main` branch
- [ ] **Full review process followed** — clarity, honor-code check, and constructive ideas appear in every review
- [ ] **User-experience additions present** — each review contributes at least one idea that improves the experience for users
- [ ] **Design language throughout** — no implementation or technical detail in any review comment
