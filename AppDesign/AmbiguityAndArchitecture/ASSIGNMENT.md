# Assignment — Ambiguity and Architecture

**Due:** Next class

---

Commit to 2 sections of the design. Elaborate each until it is unambiguous, and research the engine/platform options for your elected portion of the infrastructure. Work is done in new branches and submitted individually. This assignment is worth **15 pts**.

## Steps

1. Claim your 2 sections of the design
2. For each section, create a **new branch** named `Design_Lines_<start>-<end>` (e.g. `Design_Lines_050-104`) using the section's actual line numbers
3. Elaborate the section until **any 2 random programmers would build the same feature** from it
4. Research your elected portion of the infrastructure:
   - The options for solving it
   - Pros and cons of the main options
   - What the solution looks like — for graphical items like a HUD, include the visual itself
5. Commit the elaboration and research to the branch and push

> **Warning:**
> AI-generated graphics are not acceptable as final submissions for UI items. Manually edit graphics until they are exactly as you imagine them.

---

## Success Criteria

Confirm each of the following before submitting:

- [ ] **Solution shown** — graphical items include the actual visual, manually edited, not raw AI output
- [ ] **Work is individual and pushed** — your branches are on GitHub under your name
